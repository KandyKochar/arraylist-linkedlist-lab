# ArrayList and LinkedList Lab

A Java lab comparing ArrayList and LinkedList performance and usage through practical exercises.

## Overview
Explores Java Collections Framework by implementing operations on both ArrayList and LinkedList, demonstrating when each structure is appropriate.

## Features
- ArrayList operations: add, remove, search, sort
- LinkedList operations: queue and deque usage
- Performance comparison between list types
- Practical data manipulation examples

## Technologies Used
- **Language:** Java (JDK 8+)
- **Concepts:** Collections Framework, ArrayList, LinkedList, generics

## Project Structure
```
src/
+-- ArrayListLab.java      # ArrayList operations and examples
+-- LinkedListLab.java     # LinkedList operations and examples
```

## Usage
```bash
javac src/*.java -d out/
java -cp out/ ArrayListLab
java -cp out/ LinkedListLab
```
